# ORION TIMER 2.6 — Hybrid Mechanical Hologram

Built on the 2.5 source. No framework migration, no build step.

## Changes
- Metallic gear plates and teeth, illuminated bearing races, six exposed motor housings with independently spinning fans.
- Four routed coolant conduits with luminous cores and coupling hardware.
- Paired motorized latch arms, turbine assembly, and four mission-state lights.
- Cyan running state and amber indication during final 10 seconds.
- Upright front timer display, preserved horizontal transparent chassis and existing viewer controls.
- Corrected a piston animation offset that pushed the existing rail assembly toward the viewer.

## Publish
Extract this archive, upload the **contents** of the `ORION-Timer-2.6-Hybrid-Reactor` directory to the root of your GitHub Pages repository (including the `css` and `js` directories), and commit the changes. Do not upload the ZIP itself as the website.
